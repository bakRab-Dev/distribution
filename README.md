## 📲 インストールガイド (Android)

本アプリはGoogle Playストア外での配布となるため、初回インストール時に「不明なアプリのインストール」の許可が必要です。

### 🛠 手順
1. APKファイルをダウンロード
   - [こちら](https://github.com/bakRab-Dev/distribution/releases/latest) から最新のAPKをダウンロードしてください。
     - AssetsのbakRab-x.x.x.apkをダウンロードしてください。

2. ファイルを開く
   - 通知欄またはブラウザのダウンロード履歴からファイルを開きます。
3. 警告が表示された場合
   - 「セキュリティ上の理由から、このソースからの不明なアプリをインストールすることはできません」というメッセージが出たら **[設定]** をタップします。
4. **許可をオンにする**
   - **「この提供元のアプリを許可」** スイッチをオンに切り替えます。
5. インストール完了
   - 画面を戻り、再度 **[インストール]** をタップすれば完了です！

### ❓ よくある質問
- **Q. ウイルスやセキュリティの警告が出ます**
  - A. 開発元が不明なアプリに対してAndroidが標準的に表示する警告です。
    - 本アプリは広告ブロックとプライバシー保護を目的として開発されており、不要な権限の要求は一切行いません。

- **Q. アップデートはどうすればいいですか？**
  - A. アプリ内のアップデートボタンを押して指示に従ってください。
    - データ（NGワード設定など）を引き継いだまま更新可能です。
